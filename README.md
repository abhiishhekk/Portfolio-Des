# Abhishek Kumar — Portfolio

A revamped personal portfolio built with **React + Vite**, featuring react-bits-style animations (SplitText, BlurText, RotatingText, TiltCard, FadeContent), a black & white monochrome design inspired by [rbp-portfolio](https://rbp-portfolio.vercel.app/), and full dark/light mode support.

## Features

- ⬛ Black & white monochrome design (dark/light mode toggle)
- ✨ react-bits-style animations: `SplitText`, `BlurText`, `RotatingText`, `TiltCard`, `FadeContent`
- 🔢 Spring-animated nav pill indicator with scroll spy
- 📋 Copy-to-clipboard email in Contact section
- 📱 Fully responsive
- ♿ Accessible (skip links, ARIA labels, semantic HTML)
- 🚀 Built with Vite for fast HMR

## Sections

- **Hero** — Animated name (char-by-char), rotating roles, CTAs
- **About** — Bio, stats, tech stack by category
- **Skills** — All 20 technologies with hover effects
- **Projects** — 6 projects with TiltCard 3D hover + links
- **Education** — Timeline for MNNIT, Senior Secondary, Matriculation
- **Contact** — Copy-email card + GitHub, LinkedIn, LeetCode links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- Vite 6
- motion/react (Framer Motion)
- lucide-react
- Vanilla CSS with CSS custom properties
